- Helper: `const exName=(ex,lang)=>ex.nome?.[lang]||ex.nome?.it||ex.nome||''`
- Ogni `ex.nome` nel file → `exName(ex,lang)` (o `exName(ex,lang||'it')`)
- E94 differenziata da E25 aggiungendo "(Bodyweight)" / "poids du corps"
