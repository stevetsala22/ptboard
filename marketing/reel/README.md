# PT Board Reel - Video promozionale 30s

Video verticale (1080x1920) per Instagram Reels e TikTok.

## Setup

```bash
cd marketing/reel
npm install
```

## Comandi

```bash
npm run studio    # Apre il preview nel browser
npm run render    # Esporta MP4 completo
npm run preview   # Esporta solo i primi 3 secondi
```

## Scene (8 totali, 30 secondi)

| Tempo | Scena | Contenuto |
|-------|-------|-----------|
| 0-3s | Hook | Glitch text: "Ancora Excel e WhatsApp?" |
| 3-6s | Reveal | Mockup laptop con parallax 3D |
| 6-10s | Valutazione | Stepper animato + counter score 0-60 |
| 10-14s | Scheda | Esercizi con stagger animation |
| 14-17s | Triple | Nutrizione/Report/Calendario rapidi |
| 17-21s | Personalizzazione | Toggle tema + logo reveal |
| 21-25s | Pricing | Card bounce da lati opposti |
| 25-30s | CTA | Logo pulse + personaltrainerboard.com |
